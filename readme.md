📸 Automated Instagram Media Downloader
A specialized Python automation tool designed for content creators and marketers to efficiently download high-quality media from Instagram. This project demonstrates the ability to interact with complex social media APIs and manage large file downloads.

Key Features:

+ Dual Download Modes: Support for single post extraction via URL and bulk profile downloads via Username.

+ Smart Content Filtering: Automatically identifies and downloads images and videos while ignoring unnecessary metadata.

+ Efficient Profile Crawling: Configured to fetch the last 5 posts to prevent account flags and optimize storage.

+ Organized Storage System: Automatically creates dedicated directories for each profile or post to maintain a clean workspace.

+ Error Resilience: Robust handling for Private accounts, invalid URLs, and network interruptions.
